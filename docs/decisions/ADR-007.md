# ADR-007 · 全量查词词典独立成层（ECDICT 分片 + 懒加载）

> 日期：2026-10-23｜状态：已采纳｜部分补充 ADR-006
> 相关：US-06 点词即查、US-08 同义替换、`docs/DATA-QUALITY-DICT.md`

## 1. 背景

`bond` 卡上的同义候选 `bail / hamper / shackle / trammel` 点不开，界面只显示文本。
原因不是 UI 漏了入口，而是**数据包里没有这些词**：学习包只收 1999 个精选词，而
WordNet 同义集是全集。全库统计：7693 条候选里 **6029 条在包外**（去重 4007 个词）。

这不是个例，而是结构性缺口：只要继续用「2000 词学习包」做唯一查询源，卡上任何一个
包外词（同义候选、同源词、例句里的生词）都查不到。US-06 的「点词即查」在包外退化成
「加入生词本」，用户拿不到释义。

## 2. 决策

新增**独立的全量查词层**，与学习数据包解耦：

1. **数据源用 ECDICT**（项目已在用，MIT）：中文释义、音标、词频序号、词形变化。
2. **按首字母分片**（a–z + 其它），前端查哪个词只加载哪个片；最大片 478 KB，
   全量 4.0 MB 但从不一次性拉取。分片自带不规则变形表（`mice → mouse`、`went → go`），
   规则变形（`-s / -ed / -ing / -er / -est / -ly`、双写辅音）在运行时还原，且必须
   在词典里查到原形才算成立，不做无根据的词干猜测。
3. **收录口径**：词频序号 1~60000、或带考试标签（中高考 / 四六级 / 考研 / 雅思 / 托福 / GRE）、
   或 Oxford / Collins 标记；同时**强制收录数据包全部词条与全部同义候选**——这一条是硬约束，
   `--check-coverage` 会逐词核对，缺一个就构建失败（当前唯一例外 `swosh`：ECDICT 无此词条）。
4. **UI 三处接入**：
   - 同义候选不再按 `inPack` 禁用点击；
   - 词条弹窗 / 点词即查在数据包未命中时回落到词典，并标注「词典 · 未收录进当前考试词包」；
   - 新增「词典」页：前缀搜索、A–Z 浏览、详情、词包外的词可一键加入生词本（转 CUSTOM 卡）。
5. **离线**：分片用 Cache Storage 缓存，校验 sha256 后写入；断网时命中缓存仍可查。

## 3. 为什么不选其它方案

| 方案 | 否决理由 |
| :-- | :-- |
| 把学习包扩到 4.5 万词 | 学习包语义是「按考期排的 2000 词」，混入 4.5 万词会让新卡队列失控；包体从 4 MB 涨到 8 MB，每次重建都重算全部 sha256 |
| 只收录同义候选（4007 词） | 只解决同义区，例句里点生词、同源词仍然查不到；而且候选会随 ETL 变化，词典不该跟着抖动 |
| 后端提供 `/api/dict` 查询 | 破坏「静态可离线」的部署形态；本地单机与 PWA 离线都用不了，还引入 SQLite 词典表迁移 |
| ECDICT 全量 77 万条 | 大量人名、地名、拼写变体、短语残片；体积约 60 MB，对学习者是否噪音大于收益 |

## 4. 后果

**收益**：数据包里所有可点词汇都能查到释义（6005/6006）；包外候选从「纯文本」变成可查；
新增 4.5 万词的独立查询能力，不影响学习计划。

**代价**：
- 词包外的词只有词级中文释义（ECDICT 按词性分行），没有义项级对齐、没有例句、没有权重。
  这是刻意的：词典只回答「这个词什么意思」，不冒充学习内容。
- 静态产物 +4.0 MB（`public/dict/`），首次查某字母需拉一个分片（中位数约 150 KB）。
- 词典版本与数据包版本独立；内容变化由 manifest 的 `fingerprint` 反映，客户端据此失效缓存。

## 5. 约束（改这块前先看）

1. **必须保证数据包内所有可点词可查**：新增同义候选 / 词族成员后要重跑
   `python scripts/build_dict.py --check-coverage`，否则会出现新的「点不开」。
2. **词典不参与学习调度**：不要给词典条目补 `senseWeight` / `tier`，也不要让它进入
   `PackDictionary`——那会让「词库大小」与「计划词数」两个概念混在一起。
3. **不做机器翻译**：释义直接取 ECDICT 中文，缺失就不收录（当前因缺中文剔除的条目已在
   构建脚本里过滤），不允许用模型生成释义补空缺。
4. **分片 sha256 必须校验**：`.gitattributes` 已声明 `public/dict/** -text`，避免 Windows
   checkout 时 CRLF 转换破坏字节一致性。
