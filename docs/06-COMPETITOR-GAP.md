# 竞品卡片对照与改进计划

> 版本：v1（2026-10-21）
> 对照对象：某背单词 App 的 `cite` 单词卡（用户提供截图）
> 我方基线：ExamFlow Vocab 数据包 v1.3.0 + 当前卡片背面
> 结论：差距的主因不在视觉，而在**三个数据维度缺失**——同源词群、词汇派生、全义项英文释义。

---

## 2. 竞品卡片的信息架构（自上而下）

```
┌ 词头行    cite   UK /sʌɪt/ （发音）   US /sʌɪt/ （发音）        ☆收藏   快捷键 C
├ Tab 行    [常见单词] [柯林斯词典]                          拼写 S
├ 释义行    v. 提及，举例；引用，引进，传唤；嘉奖
├ 例句      The lawyer cited a previous case to support his argument.
│           律师引用了以前的案例来支持他的论点。                    （发音）
├ 智慧词根  base  cit-    【拉丁】唤起，刺激
├ 同源词群  citat- · cit- · -cit                       （收起 R）
│           excitement  名   ex(完全)+cit(唤起)+ment(结果)=唤起某种→兴奋   ☆
│           excited     形   ex(完全)+cit(唤起)=使兴奋                      ☆
│           excite      动   激发，刺激，引起                                 ☆
│           solicitation / solicitous / solicit / incite / excitation …
├ 词汇派生  cite → citation                                                详情 F
│           cite → cite
├ 近义词    v.  adduce  quote  mention
└ 笔记区    [官方笔记] [精选笔记] [我的笔记] [创建笔记]
            bite v. 咬，致伤 / site n.(建造的)工地 / recite v. 背诵，朗诵
            辨析 · 现在分词: citing · 变形 · 例句 · 语音
```

三个关键观察：

1. **词根是全页的组织轴**，不是一个小模块。释义、同源词群、派生、近义词都挂在 `cit-` 这一条线上。
2. **同源词群是"扩词"，形近词是"防错"**。竞品把形近辨析放进笔记区，把黄金位置留给了同根词群。
3. **信息密度高但克制**：一个模块一件事，单强调色，图标只有喇叭和星标，折叠态用 `R`/`F` 快捷键提示。

## 3. 我方卡片的信息架构（当前）

```
┌ 顶部横幅  本轮重现状态
├ 评分行    本次评分 [记错了 1] [模糊 2] [认识 3]                 拼写 S
├ 词典区    [义项权重（估计）] [英文释义]
│           1. v. 引用、引证；举例
│           （暂无英文释义）                      ← 空占位直接暴露数据缺口
│           权重为公开信号合成的估计值（满分 100），不是考试实测计数。
├ 例句      语料例句 #803443 （发音）
│           Several authors cite the same 1998 study on school size.
├ 词根      词形变化: cited / cites / citing                     收起 R
│           该词暂未收录人工词根，也没有可靠的前后缀拆分。   ← 三分之一词条是这样
├ 形近/同义 [形近词 city/bite/site] [同义 credit/reference/name/refer]
├ 考点笔记  [考点] 估计权重 75 …                                 添加笔记
```

对照后的"数据有 / 数据没有"分界很清楚：

- **数据有但展示弱**：形近词（3 个，措辞完整）、例句（有语料句）、义项权重（竞品没有的独家信号）。
- **数据本身没有**：词根（`cite` 为空）、派生（全库 0 条）、英文释义（`cite` 为空）、同源词群（概念上就不存在）。

## 5. 实测数据附录

### 5.1 `cite` 词条明细

```json
{
  "senses": [{ "pos": "v.", "cn": "引用、引证；举例", "enDef": null, "senseWeight": 75 }],
  "etymology": null,
  "forms": ["cited", "cites", "citing"],
  "sentences": 1,
  "confusables": [
    { "lemma": "city", "reason": "SOUND",     "tip": "读音相近：cite 与 city 发音接近…" },
    { "lemma": "bite", "reason": "SPELLING",  "tip": "拼写在第 1 个字母处开始不同…" },
    { "lemma": "site", "reason": "SPELLING",  "tip": "拼写在第 1 个字母处开始不同…" }
  ],
  "synonyms": [
    { "lemma": "credit",    "pos": "n.", "cn": "信用、信任、荣誉" },
    { "lemma": "reference", "pos": "n.", "cn": "参考、索引、参照" },
    { "lemma": "name",      "pos": "v.", "cn": "" },
    { "lemma": "refer",     "pos": "v.", "cn": "" }
  ]
}
```

问题一目了然：

- `enDef: null` → 界面只能显示"暂无英文释义"。
- `etymology: null` → 词根区退化成"词形变化 + 一句免责声明"。
- 近义词 `name` / `refer` 没中文，学习价值接近于零，还占了两行。
- 只有 1 个义项，而竞品给了 3 组（`传唤`、`嘉奖` 都在 ECDICT 里，被义项上限吃掉了）。

### 5.2 全库覆盖（2000 词 / 4150 义项）

| 指标 | 数值 | 说明 |
| :-- | --: | :-- |
| 有≥1 个英文释义的词 | 1850 / 2000（92.5%） | 词级覆盖率看起来还行 |
| **所有义项都有英文释义的词** | **673 / 2000（33.6%）** | 真正能"逐义项展示"的只有三分之一 |
| 有人工词根的词 | 673 / 2000（33.6%） | `cite` 不在其中 |
| 有派生词的词 | **0 / 2000（0%）** | 字段存在但从未填充 |
| 同义词总数 | 4384 条 | 其中 **3184 条（72.6%）无中文**，涉及 1454 个词 |
| 形近词分布 | SPELLING 2557 / SOUND 515 / ROOT 361 | ROOT 类只占 9.7% |
| 语料例句 | 2616 条 / 1445 词 | 另有 300 词 326 条人工例句 |
| 无例句词条 | 255 | 已标 `sentencePending`，界面明示 |
| 义项维度例句覆盖率 | 70.9% | 词条维度 87.3% |

## 6. 根因分析

### 6.1 数据层：三个维度缺数据

| 缺失 | 直接后果 | 可用的数据源 |
| :-- | :-- | :-- |
| 词根 / 词族 | 33.6% 词条"词根区"是空的；没有同源词群 | ECDICT `wordroot.txt`（611 词根，含 meaning/origin/example）+ 手工校订高频词根 |
| 派生词 | `cite → citation` 这类最有迁移价值的信息完全缺失 | ECDICT `exchange` + 全库 340 万词条的词形关系统计 |
| 全义项英文释义 | `cite` 这类词只能显示"暂无" | ECDICT `definition` 列（66 MB，构建期一次性处理） |

### 6.2 结构层：缺"扩词"这条学习路径

- 形近词回答的是"**别混**"（city / bite / site）。
- 同源词群回答的是"**一次记一串**"（excite / excitement / incite / solicit）。
- 后者是背单词产品里 ROI 最高的模块，我们完全没有。这不是"少个模块"，是少了整条学习路径。

### 6.3 展示层：卡片是"堆模块"，不是"排信息"

- 每个模块自带底色 + 徽章 + 说明文字，视觉权重相近，读者没有视线落点。
- 义项区把"权重条 + 八字说明 + 空占位"放在最显眼处，而一行就能说完的释义被拆成三行。
- 例句区每个单词都带下划线 + 溯源编号常驻，把句子读成了代码。

## 7. 修改计划

### P0 · 数据补齐与展示整理（不改结构，先止血）

| # | 任务 | 做法 | 验收标准 |
| --: | :-- | :-- | :-- |
| P0-1 | 逐义项补英文释义 | 解析 ECDICT `definition`，按词性匹配到义项；匹配不到时回退 WordNet gloss | 全义项覆盖 ≥95%；`cite` 显示 `to quote as an authority or example` |
| P0-2 | 同义词清洗 | 过滤无中文且不在词库内的项；按 ECDICT 词频排序；同词性优先 | 每条近义词都带中文，或显式标"库外"；数量 ≤4；`name`/`refer` 这类噪音消失 |
| P0-3 | 义项区合并展示 | 按词性分组，中文释义一行合并；权重条折叠到"详情"；空值不渲染占位 | `cite` 一行可读完 `v. 引用、引证；举例`；页面高度下降 ≥30% |
| P0-4 | 例句区降噪 | 下划线仅 hover/focus 显示；溯源编号收进 tooltip；第二条起默认折叠 | 例句区视觉重量与正文一致，不再"满屏虚线下划线" |

**影响面**：数据包升 v1.4.0（需重算 sha256 与 manifest）；前端改 2 个组件（`CardBackDictionary`、`CardBackSentences`）。不动卡片结构。

### P1 · 词根与词族（最大差距，需要新数据管线）

| # | 任务 | 做法 | 验收标准 |
| --: | :-- | :-- | :-- |
| P1-1 | 词根表建设 | `wordroot.txt` 611 条打底 + 手工校订高频 300 条，字段：root / 变体（`cit`·`citat`）/ 含义 / 语源 / 类别 | 覆盖率 ≥70%；抽检误判率 <5%（**禁用裸子串匹配**，必须词素边界，避免重演 `priority → ity`） |
| P1-2 | 同源词群 | 以词根为键，从 ECDICT 340 万词条召回；按常用度排序、过滤专名与生僻词；每词 6–8 个带中文 | `cite` 能召回 `excite / excited / excitement / incite / citation / excitation` |
| P1-3 | 记忆公式 | 前缀/后缀小词表（`ex-` 向外、`in-` 向内、`-ment` 名词、`-ion` 名词…）+ 词根义 → 模板拼接 | 公式中每个成分都能在词根表/词缀表里查到，不编造联想 |
| P1-4 | 派生词 | `exchange` + ECDICT 词形关系统计，产出 `cite → citation / citable` | derivatives 非空的词条 ≥60% |
| P1-5 | 卡片新模块 | 新增「同源词群」区块：词条 + 词性 + 中文 + 记忆公式 + 一键加生词本；支持折叠（`R`） | 与形近/近义词分区明确：词族=扩词，形近=防错 |

**影响面**：新增 `scripts/build_word_families.py` + `scripts/roots.json`；数据包升 v1.5.0；前端新增 1 个组件。这是工作量最大的一块。

### P2 · 结构升级与视觉收敛

| # | 任务 | 说明 |
| --: | :-- | :-- |
| P2-1 | 顶部信息条重构 | 词头行：音标 / 发音 / 星标 / 拼写入口 / 快捷键提示；下方三 Tab：学习卡 · 词典 · 笔记 |
| P2-2 | 笔记体系 | 「官方笔记」由形近辨析 + 词族提示自动生成；「我的笔记」保留现有自由输入；不做社区型"精选笔记" |
| P2-3 | 视觉收敛 | 模块统一浅灰卡片 + 单强调色；徽章只保留"熟词僻义""暂无语料例句"两类；图标只保留喇叭/星标 |
| P2-4 | 快捷键可视化 | 折叠、评分、拼写、播放的键位就地提示（竞品的 `C`/`R`/`F` 做法） |

## 8. 不照搬的部分（以及理由）

| 竞品做法 | 我方决定 | 理由 |
| :-- | :-- | :-- |
| 柯林斯词典 Tab | 不照搬，改为「自有英文释义 + ECDICT collins 星级」 | 无词典授权，不能冒充品牌；星级是公开数据，可以标注来源 |
| 精选笔记 | 不做 | 需要用户社区与内容审核，MVP 阶段是纯负担 |
| 词根联想故事 | 只做可溯源的成分拼接 | 编造联想一旦出错，对备考是负资产 |
| 同源词群不标来源 | 每个词条标 `ECDICT` 来源 | 数据可追溯，出问题能定位到构建步骤 |

**同时保留我方独有能力**（竞品没有，不要为了"像"而删）：

- 义项权重（估计）+ 熟词僻义标记 → 决定"先学哪个义项"
- 核心覆盖率 / 到期预测 → 决定"今天学什么"
- 点词即查、拼写练习、AI 私教、云同步

## 9. 风险与依赖

| 风险 | 影响 | 应对 |
| :-- | :-- | :-- |
| 词根自动匹配误判 | 误导学习者，比"没有"更糟 | 词素边界匹配 + 人工抽检 200 词；不确定就不展示 |
| ECDICT `definition` 与义项对不齐 | 英文释义张冠李戴 | 先按词性匹配，再按 WordNet 同义集校验；对不上就不显示，不硬塞 |
| 同源词群召回过多生僻词 | 模块变成词典垃圾场 | 用 ECDICT `frq`/`bnc` 排序，取前 6–8 个；专名、缩写一律排除 |
| 数据包体积增长 | 首包加载变慢 | 同源词群单独分块（按需加载），不进首屏 chunk |
| P1 改动卡片结构 | 与 P2 重复返工 | **先 P0 + P1 的数据管线，再一次性做 P2 的界面重构** |
